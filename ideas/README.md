# Ideen

**Schnelle Ideen gehören in Issues** (Template „💡 Idee“). Dort kann man voten (👍) und diskutieren.

Dieser Ordner ist für **ausgearbeitete Vorschläge**, die mehr Platz brauchen: Skizzen, Abläufe, Vergleiche.

- Dateiname: `NNN-kurzer-name.md` (z. B. `001-leselevels.md`)
- Vorlage: [`_template.md`](_template.md)
- Per Pull Request hinzufügen und das zugehörige Issue verlinken

## Ideen-Pool (Startpunkt)

Erste Ideen aus der Kickoff-Phase. Wer eine davon weiterverfolgen will, macht ein Issue daraus.

| Idee | Kurzbeschreibung | Löst welches Problem? |
|---|---|---|
| Leselevels | Abstract (5 min) / Skim (20 min) / Deep Read | Aufwand zu groß |
| Streaks + Gruppenfeed | Sehen, wer heute gelesen hat | Motivation, Accountability |
| Kuratierte Queues | Themenlisten (ML, Systems, Security …), rotierender Kurator | Auswahl: „Was soll ich lesen?“ |
| Zusammenfassungs-Template | 1 Satz Kernaussage · 3 Takeaways · 1 offene Frage | Wissen festhalten |
| Wissensgraph | Paper über Konzepte verlinken (Zettelkasten) | Wissen vernetzen |
| Spaced Repetition | Takeaways werden zu Karteikarten | Vergessen |
| LLM-Hilfe | Begriffe erklären, Fragen ans Paper, Zusammenfassung prüfen | Verständnis |
| Discord-Bot | Posten und Erinnern dort, wo wir eh sind | Einstiegshürde |
| Wöchentlicher Journal Club | 20 min Call: bestes Paper der Woche | Tiefe, Austausch |
